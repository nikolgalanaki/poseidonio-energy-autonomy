# Ενεργειακή Αυτονομία και Κλιματική Ανθεκτικότητα — Ποσειδώνιο Αθλητικό Κέντρο Θεσσαλονίκης

Υπολογιστικό μοντέλο της διπλωματικής εργασίας:

> «Ενεργειακή Αυτονομία και Κλιματική Ανθεκτικότητα Μεγάλων Αθλητικών Υποδομών:
> Μελέτη Συστήματος Φωτοβολταϊκών και Αντλιών Θερμότητας για το Ποσειδώνιο
> Αθλητικό Κέντρο Θεσσαλονίκης με χρονικό ορίζοντα το 2040»
>
> Νικολέτα Γαλανάκη — Τμήμα Μηχανικών Οικονομίας και Διοίκησης, Πολυτεχνική
> Σχολή, Πανεπιστήμιο Αιγαίου, 2026. Επιβλέπων: Κωνσταντίνος Παπαγεωργίου.

Το αποθετήριο περιέχει όλο τον κώδικα, τα δεδομένα εισόδου και τα αποτελέσματα,
ώστε κάθε αριθμός, πίνακας και σχήμα της εργασίας να μπορεί να αναπαραχθεί.

## Πεδίο

Αποκλειστικά το **κολυμβητήριο** του Ποσειδωνίου: τέσσερις δεξαμενές (δύο
εσωτερικές 50×21 m, εκμάθησης 10×12 m, εξωτερική 50×21 m), το ζεστό νερό χρήσης
των λουτρών και οι χώροι του κλειστού κολυμβητηρίου.

## Εκτέλεση

Απαιτείται Python 3.10 ή νεότερη.

```bash
python -m pip install -r requirements.txt
python calibrate.py --tmy data/tmy.csv       # Κεφ. 7
python run_analysis.py --tmy data/tmy.csv    # Κεφ. 8
python sensitivity.py --tmy data/tmy.csv     # Κεφ. 9
python sensitivity_methodology.py
python make_tables.py
python make_extra_figures.py
```

Τα αποτελέσματα γράφονται στον φάκελο `results/`. Το `cds_morphing_2040.py`
χρειάζεται λογαριασμό στο Copernicus Climate Data Store (αρχείο `.cdsapirc`)·
δεν είναι απαραίτητο να ξανατρέξει, γιατί το αποτέλεσμά του υπάρχει ήδη στο
`data/morphing_2040.csv`.

Όλες οι παραδοχές βρίσκονται στο `src/poseidonio/config.py`, κάθε τιμή με την
πηγή της.

## Βασικά αποτελέσματα

- Βαθμονόμηση: NMBE +2,4 %, CV(RMSE) 12,1 % (κριτήρια ASHRAE Guideline 14)
- Θερμική ζήτηση 3.439 MWh/έτος· SCOP αντλιών θερμότητας 3,26
- Φ/Β 500 kWp: αυτονομία 35,2 %, ΚΠΑ 1,54 M€, IRR 15,8 %, επανείσπραξη 6,6 έτη
- Φ/Β ≈700 kWp (ρεαλιστικό όριο στέγης): αυτονομία 38,7 %, ΚΠΑ 1,75 M€
- Εκπομπές CO₂: −69 % σήμερα, ≈−90 % το 2040
- Κλίμα 2040 (+0,6/+0,8 °C): ζήτηση −2,0/−2,7 %, SCOP 3,30/3,31
