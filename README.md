# Ενεργειακή Αυτονομία & Κλιματική Ανθεκτικότητα — Ποσειδώνιο Αθλητικό Κέντρο

Δημόσιο αποθετήριο κώδικα: https://github.com/nikolgalanaki/poseidonio-energy-autonomy

Υπολογιστικό μοντέλο και υλικό υποστήριξης της διπλωματικής εργασίας:

> «Ενεργειακή Αυτονομία και Κλιματική Ανθεκτικότητα Μεγάλων Αθλητικών Υποδομών:
> Μελέτη Συστήματος Φωτοβολταϊκών και Αντλιών Θερμότητας για το Ποσειδώνιο
> Αθλητικό Κέντρο Θεσσαλονίκης με χρονικό ορίζοντα το 2040»
> — Νικολέτα Γαλανάκη, Τμήμα Μηχανικών Οικονομίας και Διοίκησης (Πολυτεχνική
> Σχολή), Πανεπιστήμιο Αιγαίου

**Πεδίο μελέτης:** αποκλειστικά το **κολυμβητήριο** του Ποσειδωνίου — οι
τρεις δεξαμενές (εσωτερική 50×21 m, εσωτερική εκμάθησης 10×12 m,
εξωτερική 50×21 m), το ΖΝΧ των λουτρών και οι χώροι του κλειστού κολυμβητηρίου.
Τα ανοικτά γήπεδα και οι λοιπές εγκαταστάσεις του φορέα (Αλεξάνδρειο,
Ε.Α.Κ. Σταυρούπολης) είναι **εκτός πεδίου** και αναφέρονται μόνο ως πλαίσιο.

## Εκτέλεση

```bash
pip install -r requirements.txt             # στα Windows: python -m pip install -r requirements.txt
python3 cds_morphing_2040.py                # (έχει ήδη γίνει — data/morphing_2040.csv) ΔΤ 2040 από Copernicus CDS
python3 run_analysis.py --tmy data/tmy.csv  # με πραγματικό TMY από PVGIS (προτεινόμενο)
python3 run_analysis.py                     # με το ενσωματωμένο συνθετικό TMY (ΤΟΤΕΕ)
python3 run_analysis.py --kwp 700 --tmy data/tmy.csv   # άλλο μέγεθος Φ/Β στα σενάρια S2–S4
python3 calibrate.py --tmy data/tmy.csv     # έλεγχος βαθμονόμησης έναντι μετρητή ΕΔΑ
```

**Πλήρης αναπαραγωγή κειμένου** (μετά από κάθε αλλαγή παραμέτρων):

```bash
python3 run_analysis.py --tmy data/tmy.csv && python3 sensitivity.py --tmy data/tmy.csv
python3 sensitivity_methodology.py
python3 make_tables.py && python3 make_extra_figures.py
python3 κείμενο/make_appendices.py && python3 κείμενο/build_docx.py
```

**Θέση εγκατάστασης:** ≈ 40,597° Β, 22,950° Α (μέτρηση σε δορυφορική
εικόνα/OpenStreetMap). Το `data/tmy.csv` ελήφθη από το PVGIS για το σημείο
40,579° Β, 22,950° Α (~2 km νοτιότερα)· η διαφορά είναι αμελητέα (<0,1 %
στην ετήσια παραγωγή), γι' αυτό δεν απαιτείται νέα λήψη.

## Κλίμα 2040 — Copernicus Climate Data Store

Οι μηνιαίες μεταβολές θερμοκρασίας ΔΤ (2031–2050 έναντι 2006–2024, EURO-CORDEX
EUR-11, κελί Θεσσαλονίκης, μέσος όρος μοντέλων) υπολογίζονται από το
`cds_morphing_2040.py` και γράφονται στο `data/morphing_2040.csv`, το οποίο
διαβάζει αυτόματα το `climate.py`. Χωρίς το αρχείο, το μοντέλο τρέχει με
ενδεικτικές τιμές και εμφανίζει προειδοποίηση.

Προετοιμασία (μία φορά):
1. Λογαριασμός στο https://cds.climate.copernicus.eu
2. Αποδοχή των όρων χρήσης στη σελίδα του συνόλου
   «projections-cordex-domains-single-levels» (καρτέλα Download, στο τέλος).
3. Αρχείο `.cdsapirc` στον φάκελο χρήστη με `url: https://cds.climate.copernicus.eu/api`
   και `key: <Personal Access Token>`.

## Σενάρια

| Σενάριο | Περιγραφή |
|---|---|
| S0 | Υφιστάμενη κατάσταση: λέβητας φυσικού αερίου (βάση σύγκρισης) |
| S1 | Αντλίες θερμότητας, ρεύμα 100 % από το δίκτυο, τρέχον κλίμα |
| S2 | Α/Θ + Φ/Β (Net Billing), τρέχον κλίμα |
| S3 | Α/Θ + Φ/Β, κλίμα 2040 — σενάριο RCP4.5 |
| S4 | Α/Θ + Φ/Β, κλίμα 2040 — σενάριο RCP8.5 |

Επιπλέον, το script σαρώνει μεγέθη Φ/Β από 0 έως το θεωρητικό όριο της
στέγης (800 kWp) και εντοπίζει το βέλτιστο κατά NPV εντός του ρεαλιστικού
ορίου (≈700 kWp, μέτρηση §8.4.1) — απαντά στο ερευνητικό ερώτημα 1.

## Βαθμονόμηση με πραγματικά δεδομένα ✓

Το μοντέλο έχει βαθμονομηθεί έναντι της **πραγματικής κατανάλωσης ΦΑ του
έτους αναφοράς** (ωριαίος PTZ μετρητής ΕΔΑ Θεσσαλονίκης — Η/Μ μελέτη
τριπαραγωγής ΓΓΑ 07/2024, βλ. `docs/05-πραγματικά-δεδομένα.md`), με το
**πραγματικό TMY του PVGIS 2005–2023** (`data/tmy.csv`):

- Ετήσια: μοντέλο 3.703 MWh vs πραγματικά 3.730 MWh καυσίμου (**−0,7 %**)
- **NMBE −0,7 %** (όριο ±5 %) · **CV(RMSE) 10,3 %** (όριο 15 %) —
  πληρούνται τα κριτήρια ASHRAE Guideline 14 για μηνιαία δεδομένα
- Ο έλεγχος δεδομένων και οι διορθώσεις τεκμηριώνονται στο
  `docs/08-έλεγχος-δεδομένων.md`

## Ενδεικτικά αποτελέσματα (βαθμονομημένο μοντέλο, PVGIS TMY)

- Ετήσια θερμική ζήτηση: **≈ 3,33 GWh** τελικά (κέλυφος 42 %, ΖΝΧ 39 %,
  δεξαμενές 16 % — εκ των οποίων εξάτμιση 9 %, αερισμός 2 %)
- SCOP αντλιών θερμότητας: **≈ 3,24** (βελτιώνεται στο κλίμα 2040)
- Μείωση εκπομπών CO₂ έναντι ΦΑ: **≈ 69 %** σήμερα, **≈ 90 %** το 2040
- Με 500 kWp: αυτονομία ≈ 35 % · NPV ≈ +1,46 M€ · IRR 15,3 % · Payback ≈ 6,8
  έτη· στο ρεαλιστικό όριο στέγης (≈700 kWp): αυτονομία 38,5 %, NPV +1,67 M€
- Δυσμενέστερη περίπτωση (ΦΠΑ 24 % στο CAPEX + Α/Θ 500 €/kWth): NPV +0,73 M€

- Κλίμα 2040 (Copernicus CDS, ΔΤ +0,6/+0,8 °C): ζήτηση −2,2/−2,9 %, SCOP
  3,28/3,29, CO₂ 77/76 t (≈ −90 %)

Στα Windows οι εντολές γράφονται με `python` αντί για `python3`. Παραδοχές
προς επιβεβαίωση από τον φορέα σημειώνονται `[ΕΠΙΒΕΒΑΙΩΣΗ]` στο `config.py`.
